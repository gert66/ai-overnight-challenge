Zelf bouwen · eenvoudige route

Jij doet de eerste minuten. Daarna neemt ChatGPT het technische werk over.

Je hoeft geen Linux-beheerder te worden. Je maakt een kleine Ubuntu-server, draait één korte bootstrap en koppelt Remote Desktop Commander. Zodra ChatGPT echt een commando op de server kan uitvoeren, stopt het handmatige installatiegedeelte.

De AI-modellen draaien op afstand, dus je hebt geen GPU-server nodig. Een kleine x86 Ubuntu VM is voldoende om te beginnen.

Het hele idee in één regel

Minimum manual bootstrap → Remote Desktop Commander → ChatGPT completes and validates the workspace.

De server is pas klaar nadat tests, reboot recovery en een echte orchestrator-job zijn geslaagd.

De route

  1. 1

    Maak je accounts

    Je hebt een Hetzner Cloud-account, GitHub-account, ChatGPT en een Claude-account nodig. De browserlogins voor GitHub, Claude en Codex komen later wanneer ChatGPT ze nodig heeft.

    • Hetzner-account openen of aanmaken ↗
    • GitHub-account aanmaken ↗
    • ChatGPT openen ↗
    • Claude openen ↗
  2. 2

    Maak een kleine Ubuntu-server

    Kies x86, Ubuntu en minimaal ongeveer 2 vCPU, 4 GB RAM en 40 GB disk. Aanbevolen voor comfortabel gebruik is ongeveer 4 vCPU, 8 GB RAM en 80 GB disk. Controleer de actuele Hetzner-prijs voordat je bestelt.

    Open Hetzner Cloud Console ↗

    Exacte keuzes en SSH-uitleg →

  3. 3

    Maak de eerste SSH-verbinding

    Je gebruikt SSH alleen om de bootstrap te starten. De handleiding geeft een kopieerbaar commando voor Windows en macOS/Linux.

    Verbindingsstappen →

  4. 4

    Run de AI Challenge bootstrap

    De korte bootstrap maakt de gebruiker orchestrator, zet veilige SSH-toegang klaar, installeert Node en Remote Desktop Commander en plaatst de context- en statusbestanden voor ChatGPT.

    curl -fsSL https://raw.githubusercontent.com/gert66/ai-overnight-challenge/main/setup/bootstrap.sh -o /tmp/ai-challenge-bootstrap.sh
sudo bash /tmp/ai-challenge-bootstrap.sh

    Bekijk eerst de volledige bootstrap-broncode

  5. 5

    Koppel Remote Desktop Commander

    Na de bootstrap voer je uit:

    ai-challenge-remote

    Volg de browser-pairing. Laat de remote sessie draaien. Je kunt de tmux-weergave verlaten met Ctrl+B en daarna D.

    Open de officiële Remote Desktop Commander-uitleg ↗

    Dit is het omslagpunt: tot hier heb jij de server voorbereid. Hierna kan ChatGPT rechtstreeks bestanden, processen en terminalcommando's op de server gebruiken.
  6. 6

    Bewijs dat ChatGPT echt binnen is

    Een groen “online” lampje telt niet. ChatGPT moet op de server daadwerkelijk hostname uitvoeren en ~/AI_CHALLENGE_CONTEXT.md kunnen lezen.

  7. 7

    Geef ChatGPT de handoff-opdracht

    I have completed the AI Challenge bootstrap. Connect to my server through Desktop Commander. Read ~/AI_CHALLENGE_CONTEXT.md, ~/AI_CHALLENGE_STATUS.json and ~/AI_CHALLENGE_MANIFEST.json. Continue the installation from there. Do as much as possible yourself. Ask me only when you need an authorization, password, browser login, payment action or another action I must personally approve.

    Vanaf dit moment inspecteert ChatGPT eerst de echte machinestatus en gaat daarna zelf verder.

  8. 8

    Wacht op de echte eindcheck

    ChatGPT installeert GitHub CLI, Claude Code, Codex en de AI Orchestrator, activeert health/watchdog, draait tests, reboot de machine voor recovery-testing en voert een echte testjob uit.

    Klaar betekent: pas wanneer de volledige acceptance geslaagd is verschijnt: Your AI workspace is ready.

Waar moet jij nog terugkomen?

  • OAuth of browserlogin goedkeuren
  • 2FA of wachtwoorden invoeren
  • Een secret of API-key persoonlijk invoeren als een gekozen profiel dat nodig heeft
  • Betaling of accountacties uitvoeren
  • Expliciet toestemming geven voor destructieve cloudacties zoals een server verwijderen

Voor normale Linux-commando's, installatie, configuratie, testen en diagnose hoort ChatGPT je niet terug naar SSH te sturen zodra Remote Desktop Commander werkt.
