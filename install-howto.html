Technische hulp voor beginners

Van lege laptop naar een server waar ChatGPT zelf verder kan

Deze pagina zegt niet alleen welk commando je nodig hebt, maar ook waar je het moet typen en wat er gebeurt. Tot en met Remote Desktop Commander doe jij een paar kleine stappen. Daarna neemt ChatGPT de technische installatie over.

Eerst even: wat zijn PowerShell, SSH en een SSH-key?

PowerShellEen tekstvenster op je eigen Windows-computer waarin je commando's kunt typen. Je opent het via Start en typt PowerShell.
SSHEen beveiligde verbinding van jouw computer naar de Linux-server bij Hetzner. Na het inloggen typ je commando's rechtstreeks op die server.
SSH-keyEen digitaal sleutelpaar. De publieke sleutel mag naar Hetzner. De private sleutel blijft altijd op jouw eigen computer en deel je nooit.
Belangrijk: vóór de SSH-verbinding typ je commando's op je eigen computer. Zodra je prompt ongeveer root@jouw-server:~# laat zien, werk je op de Hetzner-server.

1. Maak eerst een SSH-key op je eigen computer

Doe dit voordat je de Hetzner-server maakt, zodat je de publieke sleutel meteen aan die server kunt koppelen.

Windows

  1. Druk op de Windows-toets, typ PowerShell en open Windows PowerShell of Terminal.
  2. Je ziet een prompt die ongeveer begint met PS C:\Users\jouwnaam>. Dat betekent: je werkt nu op je eigen computer.
  3. Kopieer het onderstaande commando met de knop en plak het in PowerShell. Druk daarna op Enter.
WAAR: op je eigen Windows-computer, in PowerShell
ssh-keygen -t ed25519 -C "ai-challenge"

PowerShell stelt daarna een paar vragen:

  • Enter file in which to save the key: druk gewoon op Enter om de standaardlocatie te gebruiken.
  • Als er staat dat het bestand al bestaat: typ n en druk op Enter. Je hebt dan al een key en hoeft geen nieuwe te maken.
  • Passphrase: voor de eenvoudigste installatie kun je twee keer op Enter drukken en hem leeg laten. Je mag ook een wachtzin kiezen, maar onthoud die dan goed.

Laat nu je publieke sleutel zien:

WAAR: nog steeds in PowerShell op je eigen computer
Get-Content "$env:USERPROFILE\.ssh\id_ed25519.pub"

Je krijgt één lange regel die meestal begint met ssh-ed25519. Kopieer die hele regel. Dit is de publieke sleutel die je straks in Hetzner plakt.

macOS / Linux

Open de app Terminal. Je werkt hier nog op je eigen computer.

WAAR: Terminal op je eigen Mac of Linux-computer
ssh-keygen -t ed25519 -C "ai-challenge"

Gebruik daarna:

WAAR: nog steeds op je eigen computer
cat ~/.ssh/id_ed25519.pub

Kopieer de volledige regel die begint met ssh-ed25519.

Nooit delen: het bestand zonder .pub, bijvoorbeeld id_ed25519, is je private key. Die blijft uitsluitend op je eigen computer.

2. Maak de Hetzner-server

Open Hetzner Cloud Console ↗

  1. Maak eventueel eerst een project en kies daarna Add Server of Create Server.
  2. Bij Image: kies Ubuntu 24.04 LTS. Als Hetzner later een nieuwere Ubuntu LTS als standaard aanbiedt, blijft 24.04 LTS voor deze handleiding een veilige keuze.
  3. Bij Architecture: kies x86, niet ARM.
  4. Kies minimaal ongeveer 2 vCPU / 4 GB RAM / 40 GB disk. Voor comfortabel gebruik adviseren we ongeveer 4 vCPU / 8 GB RAM / 80 GB disk.
  5. Zorg dat de server een publiek IPv4-adres krijgt. Dat is het nummer waarmee je straks via SSH verbinding maakt.
  6. Bij SSH Keys: kies Add SSH Key, plak de hele publieke regel uit stap 1 en geef hem bijvoorbeeld de naam mijn-laptop.
  7. Zorg dat die SSH-key geselecteerd is voor deze server en maak de server aan.
  8. Na het aanmaken zie je een Public IPv4, bijvoorbeeld 203.0.113.42. Kopieer jouw echte nummer. Je hebt het in de volgende stap nodig.
Het voorbeeld-IP 203.0.113.42 hieronder is expres nep. Gebruik altijd het echte Public IPv4-adres dat bij jouw eigen Hetzner-server staat.

3. Maak de eerste SSH-verbinding

Ga terug naar PowerShell op Windows of Terminal op macOS/Linux. Je maakt nu vanuit jouw computer een beveiligde verbinding met de server.

WAAR: op je eigen computer, dus nog niet op de server
ssh root@203.0.113.42

Vervang 203.0.113.42 door jouw echte Public IPv4-adres. Typ dus bijvoorbeeld ssh root@95.217.12.34 als dát jouw server-IP is. Zet geen haakjes om het IP-adres.

De eerste keer kan SSH vragen:

Are you sure you want to continue connecting (yes/no/[fingerprint])?

Typ dan yes en druk op Enter. Als je bij het maken van de SSH-key een passphrase hebt ingesteld, vul je die nu in.

Gelukt? Je prompt verandert nu ongeveer van PS C:\Users\jouwnaam> naar root@jouw-server:~#. Vanaf dit moment worden de volgende commando's op de Hetzner-server uitgevoerd.

4. Download en run de kleine bootstrap

Je bent nu via SSH ingelogd als root. De volgende commando's moeten dus in die SSH-sessie worden geplakt, niet in een nieuw lokaal PowerShell-venster.

Eerst download je de bootstrap:

WAAR: op de Hetzner-server, in je SSH-sessie als root
curl -fsSL https://raw.githubusercontent.com/gert66/ai-overnight-challenge/main/setup/bootstrap.sh -o /tmp/ai-challenge-bootstrap.sh

Wil je hem eerst bekijken, dan kan dat met:

WAAR: op de Hetzner-server
less /tmp/ai-challenge-bootstrap.sh

Druk op q om less weer te sluiten.

Start daarna de bootstrap:

WAAR: op de Hetzner-server, nog steeds als root
bash /tmp/ai-challenge-bootstrap.sh

Dit kan een paar minuten duren. De bootstrap maakt de gebruiker orchestrator, installeert de minimale hulpmiddelen, Node en Remote Desktop Commander, en schrijft de contextbestanden die ChatGPT later leest.

Goed teken: een geslaagde run eindigt met AI CHALLENGE BOOTSTRAP READY.

5. Start Remote Desktop Commander

Blijf in dezelfde SSH-sessie en voer uit:

WAAR: op de Hetzner-server, in dezelfde SSH-sessie
ai-challenge-remote

Je krijgt nu de pairing/login-instructies van Remote Desktop Commander. Volg de browserstap die wordt getoond. Laat de remote sessie daarna draaien.

Als je de tmux-weergave wilt verlaten zonder Remote Desktop Commander te stoppen: druk Ctrl+B, laat de toetsen los en druk daarna op D.

Open de officiële Remote Desktop Commander-uitleg ↗

Later controleren of de remote sessie nog draait:

WAAR: op de Hetzner-server
ai-challenge-remote status
Belangrijk: alleen zien dat een device “online” is, is niet genoeg. ChatGPT moet straks echt hostname kunnen uitvoeren en het contextbestand op de server kunnen lezen.

6. Geef de server over aan ChatGPT

Open ChatGPT. Zorg dat Remote Desktop Commander als plugin/connector is verbonden en start een nieuwe chat. Kopieer vervolgens deze hele opdracht:

WAAR: als bericht in ChatGPT, niet in PowerShell of SSH
I have completed the AI Challenge bootstrap. Connect to my server through Desktop Commander. First prove the connection by running hostname and whoami. Then read ~/AI_CHALLENGE_CONTEXT.md, ~/AI_CHALLENGE_STATUS.json and ~/AI_CHALLENGE_MANIFEST.json. Inspect the real machine state and continue the installation from the first incomplete step. Do as much as possible yourself. Ask me only when you need an authorization, password, browser login, payment action, secret, or another action I must personally approve. Do not send me back to SSH for routine technical work that you can perform yourself.

Vanaf dit moment hoort ChatGPT GitHub, Claude Code, Codex, de Orchestrator, systemd, health checks, watchdogs, tests en reboot-validatie zoveel mogelijk zelf af te handelen.

Recovery als iets stopt

Ik heb PowerShell of Terminal per ongeluk gesloten

Open PowerShell/Terminal opnieuw en maak opnieuw verbinding. Vervang het voorbeeld-IP door jouw echte IP:

WAAR: op je eigen computer
ssh root@203.0.113.42

Remote Desktop Commander lijkt offline

Maak eerst opnieuw SSH-verbinding en controleer daarna:

WAAR: op de server, na SSH-login
ai-challenge-remote status

Start hem zo nodig opnieuw:

WAAR: op de server
ai-challenge-remote

De installatie stopte halverwege

Start een nieuwe ChatGPT-chat met dezelfde handoff-opdracht. ChatGPT hoort eerst de statusbestanden én de echte machine te controleren en vervolgens vanaf de eerste onvoltooide stap door te gaan.

Authenticatie vraagt om mijn hulp

Dat is normaal voor OAuth, browserlogin, 2FA, wachtwoorden en secrets. Doe alleen die menselijke autorisatiestap en laat ChatGPT daarna weer verdergaan.

Hoe weet je dat alles echt klaar is?

  • Remote Desktop Commander kan een echt commando uitvoeren.
  • GitHub werkt als gebruiker orchestrator.
  • Claude Code en Codex zijn geïnstalleerd en geauthenticeerd.
  • De AI Orchestrator is geïnstalleerd.
  • Diagnostics, health en watchdog zijn groen.
  • De server is gereboot en de post-reboot checks slagen.
  • Een echte orchestrator-testjob bereikt DONE.
  • De tijdelijke bootstrap-sudo is verwijderd.
Pas dan hoort ChatGPT te melden: Your AI workspace is ready.
