Technische hulp

Alleen de bootstrap en recovery die jij zelf nodig kunt hebben

Na Remote Desktop Commander hoort ChatGPT de technische installatie uit te voeren. Deze pagina stopt daarom bewust bij de handoff en bevat daarna alleen recovery.

1. Maak de Hetzner-server

  • Image: Ubuntu
  • Architecture: x86
  • Minimum: ongeveer 2 vCPU / 4 GB RAM / 40 GB disk
  • Aanbevolen: ongeveer 4 vCPU / 8 GB RAM / 80 GB disk
  • Voeg je publieke SSH-key toe tijdens het maken van de server
Servernamen en prijzen veranderen. Kies de actuele Hetzner-variant die het dichtst bij deze specificaties ligt.

Open Hetzner Cloud Console ↗ · Account/login ↗

2. SSH-key en eerste verbinding

Windows PowerShell

ssh-keygen -t ed25519
type $env:USERPROFILE\.ssh\id_ed25519.pub

macOS / Linux

ssh-keygen -t ed25519
cat ~/.ssh/id_ed25519.pub

Plak alleen de publieke sleutel in Hetzner. Deel nooit je private key.

Na het maken van de server:

ssh root@SERVER_IP

3. Download en run de kleine bootstrap

Download hem eerst als leesbaar bestand:

curl -fsSL https://raw.githubusercontent.com/gert66/ai-overnight-challenge/main/setup/bootstrap.sh -o /tmp/ai-challenge-bootstrap.sh

Je kunt hem bekijken met:

less /tmp/ai-challenge-bootstrap.sh

Voer hem daarna uit:

sudo bash /tmp/ai-challenge-bootstrap.sh

Een geslaagde run eindigt met AI CHALLENGE BOOTSTRAP READY.

De bootstrap bevat geen wachtwoorden, API-keys of tokens. Hij installeert ook nog niet de volledige orchestrator.

4. Start Remote Desktop Commander

ai-challenge-remote

Volg de getoonde browser-pairing. De remote agent draait daarna in een tmux-sessie, zodat je SSH-venster niet permanent open hoeft te blijven.

Status bekijken:

ai-challenge-remote status

Laatste logs:

ai-challenge-remote logs

Remote Desktop Commander officiële uitleg ↗

Acceptatietest: laat ChatGPT een echt commando uitvoeren. Alleen “online” zien is onvoldoende.

5. Handoff naar ChatGPT

I have completed the AI Challenge bootstrap. Connect to my server through Desktop Commander. Read ~/AI_CHALLENGE_CONTEXT.md, ~/AI_CHALLENGE_STATUS.json and ~/AI_CHALLENGE_MANIFEST.json. Continue the installation from there. Do as much as possible yourself. Ask me only when you need an authorization, password, browser login, payment action or another action I must personally approve.

ChatGPT hoort daarna eerst de machine te inspecteren en pas daarna verder te installeren.

Recovery

SSH-sessie kwijt

Maak opnieuw verbinding met ssh root@SERVER_IP. De bootstrap is idempotent en mag opnieuw worden uitgevoerd.

Remote Desktop Commander offline

ai-challenge-remote status
ai-challenge-remote

SSH blijft altijd je noodtoegang.

Halverwege gestopt

Start een nieuwe ChatGPT-chat met dezelfde handoff-opdracht. ChatGPT leest de status, controleert de echte machine en gaat verder vanaf de eerste onvoltooide stap.

Na reboot

De orchestrator, health en watchdog moeten zelfstandig terugkomen. Remote Desktop Commander moet daarna opnieuw met een echt commando worden getest. Als de actuele Remote-versie opnieuw browserautorisatie nodig heeft, is alleen die autorisatie een menselijke stap.

Authenticatie mislukt

Laat ChatGPT de loginflow opnieuw starten. Voer wachtwoorden, 2FA en secrets zelf in. Zet ze nooit in Git of in de bootstrap.
