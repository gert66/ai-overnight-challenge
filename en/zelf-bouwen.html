Build your own · simple route

You handle the first few minutes. Then ChatGPT takes over the technical setup.

You do not need to become a Linux administrator. Create a small Ubuntu server, run one short bootstrap and connect Remote Desktop Commander. Once ChatGPT can execute a real command on the server, the manual installation phase ends.

The AI models run remotely, so you do not need a GPU server. A small x86 Ubuntu VM is enough to start.

The whole idea in one line

Minimum manual bootstrap → Remote Desktop Commander → ChatGPT completes and validates the workspace.

The route

  1. 1

    Create your accounts

    You need Hetzner Cloud, GitHub, ChatGPT and Claude accounts. GitHub, Claude and Codex browser authorization happens later when ChatGPT needs it.

  2. 2

    Create a small Ubuntu server

    Choose x86, Ubuntu and at least about 2 vCPU, 4 GB RAM and 40 GB disk. About 4 vCPU, 8 GB RAM and 80 GB disk is a comfortable recommendation. Check Hetzner's current price before ordering.

    Exact choices and SSH help →

  3. 3

    Make the first SSH connection

    You only use SSH to start the bootstrap. The detailed guide includes copy/paste commands for Windows and macOS/Linux.

  4. 4

    Run the AI Challenge bootstrap

    curl -fsSL https://raw.githubusercontent.com/gert66/ai-overnight-challenge/main/setup/bootstrap.sh -o /tmp/ai-challenge-bootstrap.sh
sudo bash /tmp/ai-challenge-bootstrap.sh

    Read the complete bootstrap source first

  5. 5

    Connect Remote Desktop Commander

    ai-challenge-remote

    Complete the browser pairing and leave the remote session running. Detach the tmux view with Ctrl+B, then D.

    This is the handoff point: up to here, you prepared the server. From here, ChatGPT can work directly with files, processes and the terminal on the server.
  6. 6

    Prove the connection

    An “online” indicator is insufficient. ChatGPT must actually run hostname and read ~/AI_CHALLENGE_CONTEXT.md.

  7. 7

    Give ChatGPT the handoff instruction

    I have completed the AI Challenge bootstrap. Connect to my server through Desktop Commander. Read ~/AI_CHALLENGE_CONTEXT.md, ~/AI_CHALLENGE_STATUS.json and ~/AI_CHALLENGE_MANIFEST.json. Continue the installation from there. Do as much as possible yourself. Ask me only when you need an authorization, password, browser login, payment action or another action I must personally approve.
  8. 8

    Wait for the real acceptance result

    ChatGPT installs GitHub CLI, Claude Code, Codex and the AI Orchestrator, enables health/watchdog, runs tests, reboots for recovery testing and executes a real test job.

    Done means: only after full acceptance passes should you see Your AI workspace is ready.

When does the human come back?

  • OAuth or browser authorization
  • 2FA or passwords
  • Entering a secret or API key when a selected profile requires one
  • Payment or account actions
  • Explicit approval for destructive cloud actions such as deleting a server

If something stops halfway

The bootstrap is safe to re-run. SSH remains emergency access. A new ChatGPT session can read the context and status files, inspect the real machine and continue from the first incomplete step.
