Requirements & cost

You mainly need a small server and your existing AI accounts.

The models do not run on your VM. The server is the permanent home for Git, the orchestrator, tests, health monitoring and Remote Desktop Commander.

Cloud prices and server names change. The DIY guide therefore uses specifications instead of one hardcoded Hetzner product name or an old monthly price.

What you do not have to build

You do not have to program a state machine, watchdog or Git safety layer from scratch. The canonical AI Orchestrator Starter already contains those pieces. The DIY route gets you to the point where ChatGPT can install them directly.
