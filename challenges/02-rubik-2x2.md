# 2. 2x2x2 Rubik Solver

## What is the challenge?
Build a browser application that accepts a valid 2x2x2 cube state, checks it, solves it automatically and shows the solution on an interactive 3D cube.

## Input available
No private data is needed. The application can generate random valid scrambles itself. Public solver references may be consulted.

## What should we see tomorrow?
A clean 3D cube, scramble input/generation, validity check, solution move list, move count and animated playback.

## Acceptance test
Solve several random valid scrambles and verify every solution by applying all moves back to the internal cube model.
